# LifeOS ✦ Your Personal Life Operating System

> Run your life like a system.

LifeOS is a full-stack productivity app where your habits, goals,
tasks, and memories orbit around you.

## Tech Stack
- **Frontend:** Next.js, React, TypeScript, Tailwind CSS, GSAP, Framer Motion, Recharts
- **Backend:** Python, FastAPI, Pydantic, JWT
- **Database:** MongoDB
- **Deployment:** Vercel (frontend), Render (backend)

## Modules
Life Command Center · Habit Playground · Goal Universe · Task Planner ·
Time Reality · Memory Vault · Future Self · Weekly Life Review

## Project Structure
- `frontend/` – Next.js app
- `backend/` – FastAPI app
